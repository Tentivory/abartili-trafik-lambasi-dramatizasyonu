# Abartılı Trafik Lambası Dramatizasyonu

## Giriş

Bu repository, dünyanın en ciddi, en abartılı ve tamamen gereksiz trafik lambası dramatizasyon sistemidir. Trafik ışıkları sadece renk değildir; onlar varoluşun, özgürlüğün ve beklemenin metaforlarıdır. Bu proje, her ışık değişimini epik bir drama haline getirir.

**Uyarı:** Bu kod gerçekten çalışır. Python 3 ile çalıştırın. Trafiğe çıkmadan önce kullanmayın, yoksa geç kalırsınız.

## Kurulum

```bash
git clone https://github.com/Tentivory/abartili-trafik-lambasi-dramatizasyonu.git
cd abartili-trafik-lambasi-dramatizasyonu
python3 trafik_dramatizasyonu.py
```

## Özellikler

- Kırmızı ışıkta varoluşsal kriz tetikler.
- Sarı ışıkta felsefi tereddüt yaratır.
- Yeşil ışıkta özgürlük sorgulaması başlatır.
- Rastgele dramatizasyon mesajları.
- Abartılı bekleme süreleri (gerçekçi değil, ama hissettirir).

## Bilimsel Temel

Bu sistem, kuantum trafik teorisi ve varoluşçu felsefenin birleşiminden doğmuştur. Her ışık, bir olasılık dalgasıdır. Yeşil yandığında dalga çöker, kırmızıda süperpozisyon devam eder.

## Katkıda Bulunma

Pull request atmayın. Bu proje zaten mükemmel. Eğer isterseniz, kendi dramatizasyonunuzu ekleyin ama abartmayın. Abartmak yasak değil, zorunlu.

## Lisans
